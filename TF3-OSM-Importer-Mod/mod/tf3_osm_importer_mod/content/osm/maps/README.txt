Put converted OSM .lua map files in this folder before starting TF3.
Keep different map files under different filenames.
In the game: OSM Import > Choose .lua map > Check map and match objects.
Start import only after checking the map dimensions and heightmap alignment.
Keep the original selected file for saved imports. Restart TF3 after adding
or replacing map resources. Do not put scripts, saved games or heightmaps here.
