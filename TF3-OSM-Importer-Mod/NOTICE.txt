TF3-OSM-Importer-Mod, GPL-3.0

This standalone in-game package shares its revision 6 Lua runtime with
OSM-TF3-Vanilla-Converter Preview 0.12. Its modId remains
druttzen_osm_vanilla. The fictional sample dataset is unchanged.
Install one copy of this mod only.

The TF3 rebuild is inspired by VacuumTube's OSM-TPF2-Importer 1.5.
The original GPL-3.0 license and VacuumTube/Druttzen attribution are retained.
The original TF2 source is separate from this TF3 rebuild.

Transport Fever 3 vanilla assets are referenced by resource name. No game
models, textures, audio, API source files or game executables are distributed.

The sample dataset is fictional. Real OpenStreetMap data requires
attribution to OpenStreetMap contributors and compliance with ODbL.
https://www.openstreetmap.org/copyright

The desktop converter and Pillow belong to companion tool 1 and are not
bundled here. The installable mod's NOTICE is focused on this game component.
The optional automated Lua tests use Lupa as a development dependency.

Preview: the fictional sample imports in TF3 Windows build 40408.
See README.md and validation.json for completed checks and remaining work.
